ORM(Object Relational Mapper):-
=====================================
Layer of abstraction that sits between database and us
we can perform all database operations hrough traditional python code , no more sql 

                  python                  Psycopg2(sql)
Fastapi <---------------------> ORM <-------------------->Database 

Instead of manually defining tables in postgres, we can define tables as models 
queries can be made excluesively through python code ,No sql necessary 

SQLAlchemy is one of the most popular python ORM  => pip install sqlalchemy
it is standalone library and has no association with FASTAPI ,it can be used with any other web Framework(django,flask) pr any python based aplication
